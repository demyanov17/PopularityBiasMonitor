# Программный инструмент мониторинга предвзятости популярности в рекомендательных системах

Инструмент для мониторинга предвзятости популярности в пакетных рекомендательных системах. Разработан в рамках магистерской диссертации. Архитектура решения включает в себя четыре модуля:

- обработка данных (Data Processor)
- расчёт метрик предвзятости популярности (Popularity Bias Metrics)
- визуализация (Visualization)
- пользовательский интерфейс (User Interface)

---

## Сборка и запуск

Для запуска проекта выполните в терминале следующие команды:

- `pip install -r requirements.txt`
- `streamlit run interface.py`

Параметры можно гибко настраивать через конфигурационный файл `config.yaml` для проведения различных экспериментов.
